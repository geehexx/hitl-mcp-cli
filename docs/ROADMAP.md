# Roadmap

Items implemented in v0.9.0 have been removed from this file. The following are genuine future considerations:

## Accessibility
- **High contrast theme** — implement a `--theme high-contrast` option for users with visual impairments
- **Screen reader testing** — test with NVDA, JAWS, VoiceOver and fix any compatibility issues

## Testing
- **Cross-platform CI** — automated test runs on macOS and Windows in addition to Linux

## Documentation
- **Video tutorials** — screen recordings of common agent integration workflows
- **Agent integration examples** — sample code for LangChain, AutoGen, CrewAI, and custom agents
